# RELEASE REPORT v2.53: The published standard

Three schemas and the normative document. The formats stop being an
implementation detail and become a standard anyone can build against,
with CI holding the standard and the implementation equal in both
directions.

## What shipped

schemas/reqpub-baseline-bundle.schema.json,
schemas/reqpub-receipt.schema.json, and
schemas/reqpub-evidence-manifest.schema.json, JSON Schema draft 2020-12,
each carrying its served $id, generated from the implementation's exact
output shapes and frozen. Hex fields are pinned to 64 lowercase
characters, format and formatVersion are constants, the issuer name is
the constant ReqPub, and the receipt's chain block admits the honest
null-with-reason shape the seal function emits when the chain is
unavailable.

../SPEC.md is the normative document: field-by-field required tables
for all three formats, the canonicalization pointer to VERIFY.md clause
3, the seal and timestamp semantics pointer to section 9, the versioning
policy stating additive-only within a formatVersion with both versions
published across a break, and the license line marked OWNER TO CONFIRM
per standing decision D1. The standing invariant is stated in its exact
words: verified by exact bytes and canonical JSON per VERIFY.md; no
JSON-LD processing, no RDF canonicalization, no Data Integrity proofs,
now or in any future formatVersion.

scripts/spec-schema-parity.mjs holds SPEC.md's tables equal to each
schema's required lists at every named level: top-level fields, nested
parent.child rows, and array item rows, both directions, with the exact
field named on any drift. The test suite validates the CURRENT builders'
live output, not fixtures: buildVerifyBundle, buildReceipt in both its
chained and chain-unavailable shapes, and the evidence pack manifest all
pass through ajv against the frozen schemas on every push, so the
implementation cannot drift from the standard without the build failing.
The negative cases prove the teeth: a missing snapshot, a string seq, a
non-hex fingerprint, a receipt without its signer domain, a foreign
issuer, and a hashless manifest entry are all refused.
