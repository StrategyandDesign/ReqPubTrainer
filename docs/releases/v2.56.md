# RELEASE REPORT v2.56: Pursuit Mode and engagement lineage

The scope conversation gets its own shape, and a record can finally say
where it came from without anything flowing across the link.

## What shipped

Pursuit Mode is an authored control field, orthogonal to document type.
The worksheet trim is one additional clause on the same per-section
condition filter the engagement toggle has used since v2.20, so a
non-pursuit record renders exactly as before, pinned by test at the
source. A pursuit carries the scope-bearing sections only: control,
objective and context, success metrics, scope and approach, assumptions
and dependencies, stakeholders. The Pursuit template start sets the
control and opens the Document tab.

The three-step header is a pure view over facts already in state:
baselines captured, whether an unrevoked share exists, whether an
unrevoked signature exists. It carries no controls, because the buttons
that capture, share, and sign are the ordinary ones already on the page
and two paths to one action is a defect. It scores nothing: no
percentage, no step count, no next step. Revoked shares and revoked
signatures are not facts, and the tests say so.

Promote turns a signed pursuit baseline into an engagement. It recomputes
the fingerprint through core.js and asserts equality with the sign
request's stored value before creating anything; a mismatch aborts with a
plain message and writes nothing. On a match it creates the child,
carries authored scalars across through the same rev-checked, additive,
sequential field RPC every template start uses, with live progress, and
records the citation. The pursuit flag does not cross. Practice does, the
single deliberate exception: a rehearsal's child is a rehearsal.

Lineage is three additive nullable columns and one set-once definer RPC.
A manager on the child sets it once; the second attempt is refused rather
than overwritten. Format is validated before any write: sixty-four
lowercase hexadecimal characters, one canonical form, uppercase refused.
The write logs lineage.set with the citation in its meta and rides the
activity chain. The cover carries one quiet Born from line with the
reference and twelve characters of the fingerprint, and renders nothing
at all on a partial citation.

## The property that matters

Nothing reads back up the chain. A citation may name a record in another
organization, and the backend suite deletes the cited record and proves
the citation still stands, because the fingerprint is the proof and no
query joins against the parent. A lineage is a citation, not a pipeline.

the header helper emitted a dynamic data-action, breaking the rule that
every handler traces to literal markup. The header needed no actions at
all, so the parameter came out and symmetry was restored.
