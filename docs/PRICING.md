# Pricing

The single source of truth for every price ReqPub publishes. A figure that
appears on the website and not here fails the claims gate, so the two cannot
disagree.

**Decided by the owner, 5 August 2026.** These are commercial figures, not
derived values. They are recorded here so that everything downstream, the
website, the line item exhibit, and any proposal, reads from one file.

## The shape

Priced per record. Never per seat, and never a percentage of program value.
Everyone who authors, reviews, approves, or signs is included at every tier. A
record that costs more when another reviewer joins is a record that will not
get the review it needed.

## Tiers

| Tier | Price | Scope |
| --- | --- | --- |
| Pursuit record | $7,500 | A scope-bearing baseline for the proposal or funding stage, before the work is contracted. Credits in full toward the engagement tier when the work proceeds |
| Engagement record | $38,500 | One program under five million dollars. Twelve months. Sealing, evidence pack, close package |
| Program record | $85,000 | Programs from five to twenty-five million dollars. Multiple baselines, multiple gates, webhooks, agent read surface |
| Enterprise program record | $185,000 | Programs above twenty-five million dollars, or portfolios running several workstreams against one record. Everything above, plus priority incident response and a verification session delivered to the client's security function |
| Programme agreement | $750,000 | Ten program records, drawn down as needed, over twenty-four months |

## What is not included at any tier, stated here so nobody has to ask

Source escrow is offered but not yet executed; there is no agent engaged and
no agreement signed, and `VENDOR_PACK/ESCROW.md` says so. It is therefore not
listed as a tier inclusion. When it is executed it moves into the enterprise
tier and this file changes first.

Change exhibits are not listed as an inclusion because the one-click change
exhibit is not built. The underlying evidence is: exact requirement-level
diffs between approved baselines, with named approvals and dates, available
today through the Changes view and every export.

## The anchor, for a room

On a five million dollar program the Program record is one and seven tenths of
one percent of program value. Whether that is worth it is the client's
judgment and not a claim this file makes.
